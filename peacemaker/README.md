# 피스메이커 — 수업용 화면

고등부 15분 공과(A안·B안)를 장면 단위로 넘기며 진행하는 정적 웹페이지입니다.

- `index.html` 화면과 동작, `lesson.js` 수업 내용, `cues.json` 영상 구간 설정, `assets/` 그림과 사진
- 영상은 유튜브 플레이어를 페이지 안에 넣고, 정해 둔 시작~끝 구간만 재생한 뒤 멈춥니다.
- 구간 맞추기: 페이지의 **구간 편집** → 유튜브 주소 붙여넣기 → 영상을 보면서 **지금 위치 → 시작 / 끝** → **내보내기**로 나온 내용을 `cues.json`에 저장
- 직접 가진 영상 파일은 `assets/`에 넣고 주소 칸에 `assets/파일이름.mp4`를 적으면 같은 방식으로 구간 재생됩니다.

## 실행

유튜브 재생은 http/https 주소에서만 됩니다(파일을 더블클릭해서 열면 안 됨).

- PC에서: 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`
- 인터넷에 올리기: 이 폴더를 그대로 GitHub Pages 또는 Cloudflare Pages에 배포(빌드 과정 없음)
