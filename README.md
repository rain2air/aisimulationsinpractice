# 투표 플랫폼

로그인 없는 웹 투표 플랫폼 (Node 18+, 외부 의존성 없음).

- 투표 명칭(회장, 총무 …)별로 별도 투표, 각각 1인 1표
- 상태: 준비중 → 진행중 → 마감. 시작 전·마감 후에는 투표/취소 불가
- 진행 중에는 투표 취소 후 재투표 가능
- 관리자: 화면 오른쪽 위 "관리자" 버튼 → 비밀번호(기본 `root`) 입력 → 관리자 메뉴
  (비밀번호 변경, 투표 명칭 추가/변경/삭제, 후보 등록/삭제, 투표 시작/마감)
- 모든 투표의 결과가 명칭별로 누적 표시

```bash
npm start   # http://localhost:3000
npm test
```

환경변수: `PORT`(3000), `DATA_FILE`(data.json). 배포 시 `DATA_FILE`이 영구 저장소(볼륨)를 가리켜야 데이터가 유지됩니다. `Dockerfile` 포함.

> 기본 비밀번호 `root`는 첫 로그인 후 반드시 변경하세요.
> 한계: 쿠키 기반 식별이라 쿠키 삭제/시크릿 창으로 재투표가 가능합니다.
